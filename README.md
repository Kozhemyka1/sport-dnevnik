# СПОРТ.ДНЕВНИК

Пиксельное приложение-дневник тренировок (ноябрь–декабрь 2026, 4 недели).

- Расписание тренировок по дням недели (автоопределение сегодняшнего дня)
- Разминка и заминка по шаблонам
- Кнопка `?` у каждого упражнения — краткое описание техники
- Запись рабочих весов и заметок в день тренировки
- Дневник всех записей + экспорт/импорт JSON
- Вкладка ИНФО: правила месяца, замеры «до», обозначения

Данные дневника хранятся локально в браузере (localStorage) — не синхронизируются между устройствами.

## Локальный запуск

```bash
npm run dev   # http://localhost:7100/
```

Или просто открыть `index.html` через любой статический сервер.

## Деплой
