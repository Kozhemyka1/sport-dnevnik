# ROADMAP — Спорт-дневник

Зафиксировано 25.11.2026. Текущее состояние: статический сайт на GitHub Pages
(kozhemyka1.github.io/sport-dnevnik), данные в localStorage, программа зашита в src/data.js.

## Этап 1 — Серверная база (фундамент)
- [ ] Серверный сервис (FastAPI/Express + SQLite) на сервере пользователя
- [ ] HTTPS: бесплатный сабдомен (DuckDNS) + Let's Encrypt, или купленный домен
- [ ] API хранилища: программа + дневник (загрузка/сохранение)
- [ ] Офлайн-режим: localStorage как кэш, досылка записей при появлении связи
- [ ] Переезд фронта с GitHub Pages на сервер (единый адрес)
- [ ] Бэкапы базы (раз в день)

## Этап 2 — Аккаунты без регистрации
- [ ] Экран входа: логин + пароль, без персональных данных
- [ ] Предвыданные аккаунты: генерация пар логин/пароль (команда или админка)
- [ ] Сессионные токены (30 дней), bcrypt-хэши паролей
- [ ] Изоляция данных: у каждого аккаунта своя программа и дневник
- [ ] Удаление/сброс аккаунта (отзыв доступа)

## Этап 3 — Конструктор программы
- [ ] ID упражнений (переименование не ломает историю весов)
- [ ] Редактирование: веса, схемы, примечания
- [ ] Добавление/удаление упражнений в дне, порядок
- [ ] Добавление/дублирование дней и недель
- [ ] Сброс к базовой программе
- [ ] Программа как стартовый шаблон для новых аккаунтов

## Этап 4 — ИИ через Groq
- [ ] Прокси к Groq на сервере (ключ только на сервере)
- [ ] Автоописание упражнения по названию + кэш в базе (саморастущий словарь)
- [ ] Нечёткий поиск по словарю
